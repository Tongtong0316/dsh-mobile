  DeepSeek Harness（安卓版）· 使用说明
══════════════════════════════════════════════════

【这是什么】
DeepSeek Harness（dsh）的安卓原生应用封装：把完整的 dsh
运行时（Node.js + dsh 0.2.0-rc.2）打包进一个 APK，点开图标
直接进入 dsh 网页界面，开箱即用——不需要安装 Termux、
Node、命令行，也不需要任何电脑辅助。

【设备要求】
• arm64 架构的手机/平板（2018 年后的安卓设备基本都是）
• Android 8.0 或更高
• 可用存储空间 ≥ 1.5 GB（安装后首启会解压约 500 MB 运行时）
• 系统自带 WebView 即可，无其他依赖
※ 不支持：x86 模拟器、极旧的 32 位设备

【安装步骤】
1. 邮件附件共有 4 个分卷（.z01 .z02 .z03 .zip），
   全部下载到手机同一文件夹（或同一电脑文件夹）
2. 解压合并：
   • 安卓：用 ZArchiver（应用商店免费下载）选中全部
     4 个分卷 → 解压到当前目录，得到完整 apk
   • 电脑：用 7-Zip / Bandizip 直接解压第一个分卷即可
3. 把 apk 装到手机：点开安装，若提示"未知来源/安装未知应用"，
   去设置里允许当前来源安装，再返回继续
4. 打开"DeepSeek Harness"图标

【首次启动】
黑屏几秒 → 出现鲸鱼图标 + 转圈（正在解压运行时，约
139 MB，视设备速度 30~90 秒）→ 自动进入欢迎界面。
请保持屏幕亮着等它完成，之后每次打开都是秒级进入。

【首次配置（重要）】
本安装包已彻底清空一切个人配置（模型、API 密钥、插件均未
包含）。进入界面后：
• 左下角 设置 → 模型：添加你要用的大模型
  （支持 OpenAI 兼容接口 / DeepSeek 官方账号登录等方式）
• 配好后新建会话即可对话，体验与电脑版 dsh 完全一致

【日常使用】
• 数据（会话/设置）全部保存在手机本地，卸载会清除
• 建议在"最近任务"里把本应用卡片锁定（下拉卡片点锁定），
  避免系统清理后台杀掉运行时；万一被杀，重新打开即可，
  数据无损
• 部分小米/华为设备首次使用建议在设置中授予"后台运行"
  与"无限制电量"权限

【常见问题】
Q：打开后一直黑屏/鲸鱼转圈超过 3 分钟？
A：首次解压在低端机上较慢；若确实卡死，彻底关闭应用
   再打开一次（会断点续解压）。

Q：提示"引擎启动超时"？
A：多为存储空间不足（需 ≥1.5GB）或系统拦截，清理空间、
   允许自启动后重开。

Q：升级新版？
A：直接安装新 apk（同签名覆盖安装），会话与设置自动保留。
